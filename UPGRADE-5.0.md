# Upgrading from prepositioner 4.x to 5.0

This file lists the changes in 5.0 that may need work in your application. The full list of changes is in [CHANGELOG.md](https://github.com/tomaj/prepositioner/blob/master/CHANGELOG.md).

Checklist:

- PHP 8.4 or newer: [Requirements](#requirements).

## Requirements

- PHP 8.4 or newer (4.x ran on PHP 8.2+).

```json
{
    "require": {
        "php": "^8.4",
        "tomaj/prepositioner": "^5.0"
    }
}
```
